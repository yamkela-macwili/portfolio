# Yamkela Macwili - Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS.

## 🚀 Overview

This project showcases my work as an Aspiring AI Systems Engineer. It features a clean, minimalist design with interactive elements, smooth animations, and a focus on performance and accessibility.

## 📚 Documentation

Comprehensive documentation is available in the `doc/` directory:

-   [**Architecture**](doc/architecture.md): Overview of the project structure, tech stack, and key architectural decisions.
-   [**Components**](doc/components.md): Detailed documentation for core and page components.
-   [**Setup**](doc/setup.md): Instructions for setting up, running, and building the project.
-   [**Styling**](doc/styling.md): Guide to the design system, color palette, and animation strategy.

## 🛠️ Tech Stack

-   **React 19**
-   **TypeScript**
-   **Tailwind CSS v4**
-   **Motion**
-   **Vite**

## 🏃‍♂️ Quick Start

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Start the development server:**
    ```bash
    npm run dev
    ```

3.  **Build for production:**
    ```bash
    npm run build
    ```
